Curso de Tecnología Web

Aprende las bases del desarrollo web y crea tus propias páginas utilizando HTML, CSS, JavaScript y herramientas de control de versiones como Git.

Ir al formulario de contacto Visita la Universidad

¿Qué aprenderás?

  • HTML5
  • CSS3
  • JavaScript
  • Git y GitHub

Este curso está diseñado para que adquieras habilidades prácticas y puedas desarrollar proyectos web.

Pasos para tu proyecto web

  1. 1 Planifica tu proyecto.
  2. 2 Crea la estructura de tu página.
  3. 3 Agrega el contenido y los elementos.
  4. 4 Prueba y mejora tu sitio.
